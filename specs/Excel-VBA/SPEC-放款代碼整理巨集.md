# 放款代碼整理巨集 — 技術規格文件 (SPEC)

## 1. 文件資訊

| 項目 | 內容 |
|------|------|
| 文件名稱 | 放款代碼整理巨集規格書 |
| 版本 | v1.0 |
| 適用來源檔 | 全行連線系統放款類作業一覽表(綠卡)，例：`11507.xls` |
| 開發語言 | VBA (Excel Macro) |
| 主控巨集 | `BuildAllPropertyLists` |
| 執行方式 | 開啟一次來源檔，一次產出 5 張目的工作頁 |

---

## 2. 系統概述

本巨集用於將「放款類作業一覽表（綠卡）」中的多個代碼對照工作頁，
自動解析並整理成結構化的目的資料表，供後續查詢、比對或匯入系統使用。

- 使用者透過檔案選擇視窗指定來源檔（唯讀開啟，不修改來源）。
- 主控巨集依序呼叫 5 支功能函式，各自產出一張目的表。
- 產出的目的表建立於「本活頁簿」（`ThisWorkbook`），若已存在則清空後重建。
- 所有代號欄位設為文字格式（`@`），保留前置 0。

---

## 3. 功能規格

### 3.1 功能對照總表

| 編號 | 功能函式 | 來源工作頁 | 目的工作頁 | 欄位數 |
|------|----------|-----------|-----------|--------|
| F1 | `BuildPropertyTypeMaster` | 性質別 | `PROPERTY_TYPE_MASTER_LIST` | 2 |
| F2 | `BuildPropertyTypeDetail` | 性質別細目﹙憑證種類﹚ | `PROPERTY_TYPE_DETAIL_LIST` | 4 |
| F3 | `BuildObjectTypeList` | 對象別 | `OBJECT_TYPE_LIST` | 3 |
| F4 | `BuildCollateralList` | 擔保品 | `COLLATERAL_TYPE_LIST` | 2 |
| F5 | `BuildPolicyLoanList` | 商品別(政策性貸款種類) | `POLICY_LOAN_LIST` | 2 |

---

### 3.2 F1：性質別主表

| 項目 | 內容 |
|------|------|
| 目的工作頁 | `PROPERTY_TYPE_MASTER_LIST` |
| 輸出欄位 | 性質別代號、性質別名稱 |
| 來源對應 | 性質別代號 = A 欄 + C 欄；性質別名稱 = B 欄 + D 欄 |
| 解析邏輯 | 逐列處理，先抓左組 (A,B)，再抓右組 (C,D)，合併為單一清單 |
| 排除規則 | 表頭列（代號）、跨欄合併標題（代號 = 名稱）、空白列、代號長度 > 4 |

### 3.3 F2：性質別細目表

| 項目 | 內容 |
|------|------|
| 目的工作頁 | `PROPERTY_TYPE_DETAIL_LIST` |
| 輸出欄位 | 性質別代號、性質別名稱、性質別細目代號、性質別細目名稱 |
| 來源對應 | A 欄=「名稱（代號）」；B 欄=細目代號；C 欄=細目名稱 |
| 解析邏輯 | 由 A 欄「名稱（代號）」拆出代號與名稱；A 欄空白時沿用上一筆有效值 |
| 括號處理 | 全形（）、半形()、小型﹙﹚統一正規化為全形（） |
| 輸出條件 | B 或 C 欄任一有值才輸出一筆 |

### 3.4 F3：對象別

| 項目 | 內容 |
|------|------|
| 目的工作頁 | `OBJECT_TYPE_LIST` |
| 輸出欄位 | 對象別名稱、本行對象別代號、央行對象別代號 |
| 來源對應 | A 欄=名稱；B 欄=本行代號；C 欄=央行代號 |
| 排除規則 | 表頭列、兩代號皆空的說明列、以「備註」開頭的列 |
| 對齊 | 名稱欄靠左 |

### 3.5 F4：擔保品

| 項目 | 內容 |
|------|------|
| 目的工作頁 | `COLLATERAL_TYPE_LIST` |
| 輸出欄位 | 擔保品代號、擔保品說明 |
| 來源對應 | 代號 = A 欄 + C 欄；說明 = B 欄 + D 欄 |
| 排除規則 | 表頭列、含頓號「、」的區塊標題（如「0、無實質擔保品」）、說明空白列、代號長度 > 5 |
| 對齊 | 說明欄靠左 |

### 3.6 F5：商品別（政策性貸款種類）

| 項目 | 內容 |
|------|------|
| 目的工作頁 | `POLICY_LOAN_LIST` |
| 輸出欄位 | 代碼、說明 |
| 來源對應 | A 欄=代碼；B 欄=說明（只取前兩欄） |
| 排除規則 | 表頭列（代碼／代號、說明）、代碼或說明任一為空的列 |
| 對齊 | 說明欄靠左 |

## 4. 程式架構

### 4.1 模組結構

```
Module1
├── BuildAllPropertyLists           (Public，主控巨集)
├── BuildPropertyTypeMaster         (Private，F1)
├── BuildPropertyTypeDetail         (Private，F2)
├── BuildObjectTypeList             (Private，F3)
├── BuildCollateralList             (Private，F4)
├── BuildPolicyLoanList             (Private，F5)
└── 共用輔助函式
    ├── TryAddCodePair              (性質別主表用：抓代號/名稱組)
    ├── TryAddCollateral            (擔保品用：抓代號/說明組)
    ├── GetOutputSheet              (取得/建立目的工作頁)
    ├── FormatOutput                (統一美化輸出表)
    ├── NormalizeBrackets           (括號正規化)
    ├── SplitProperty               (拆解「名稱（代號）」)
    └── CellDisp                    (讀取儲存格值，處理合併儲存格)
```

### 4.2 主控流程

```
BuildAllPropertyLists
  1. 顯示 FileDialog 讓使用者選擇來源檔
  2. 以唯讀方式開啟來源活頁簿（只開一次）
  3. 依序呼叫 F1 ~ F5，各回傳整理筆數
  4. 關閉來源檔（不儲存）
  5. 彈出彙總訊息（各表筆數）
  * 任何錯誤 → CleanUp：確保關閉來源檔並還原設定
```

## 5. 共用輔助函式規格

| 函式 | 輸入 | 輸出 | 說明 |
|------|------|------|------|
| `GetOutputSheet(sheetName)` | 工作頁名稱 | Worksheet | 存在則清空、不存在則建立於最後 |
| `FormatOutput(ws, outRow, colCount)` | 目的頁、末列、欄數 | 無 | 表頭粗體＋灰底、框線、AutoFit、凍結首列 |
| `NormalizeBrackets(s)` | 字串 | 字串 | 括號變體統一為全形（） |
| `SplitProperty(s, code, nm)` | 字串 | code, nm | 由「名稱（代號）」拆出代號與名稱 |
| `CellDisp(ws, r, c)` | 頁、列、欄 | 字串 | 讀顯示值；合併儲存格取左上角 |
| `TryAddCodePair(...)` | 頁、列、代號欄、名稱欄、目的頁、outRow | Boolean | 有效則寫入並回傳 True |
| `TryAddCollateral(...)` | 頁、列、代號欄、說明欄、目的頁、outRow | Boolean | 有效則寫入並回傳 True |

## 6. 資料排除規則彙整

| 排除類型 | 判斷條件 | 適用功能 |
|----------|----------|----------|
| 表頭列 | 值 = 「代號」/「代碼」/「性質別」/「說明」 | 全部 |
| 跨欄合併標題 | 代號值 = 名稱值 | F1 |
| 分類區塊標題 | 代號欄含頓號「、」 | F4 |
| 說明性長字串 | 代號長度 > 4（F1）/ > 5（F4） | F1、F4 |
| 空白列 | 代號或名稱任一為空 | 全部 |
| 備註列 | 名稱以「備註」開頭 | F3 |

---

## 7. 特殊處理

| 情況 | 處理方式 |
|------|----------|
| 括號不一致 | 全形（）、半形()、小型﹙﹚(Unicode FE59/FE5A) 統一辨識 |
| 合併儲存格 | 取合併範圍左上角值（`MergeArea.Cells(1,1)`） |
| 前置 0 保留 | 代號欄設文字格式 `@` |
| 代號沿用 | F2 中 A 欄空白時，沿用上一個有效性質別代號／名稱 |
| 工作頁找不到 | 彈出提示訊息並回傳 0 筆，不中斷其他表整理 |

## 9. 錯誤處理

| 情境 | 系統行為 |
|------|----------|
| 使用者取消選檔 | 顯示「已取消」訊息並結束 |
| 找不到指定工作頁 | 顯示提示訊息，該表回傳 0 筆，續跑其他表 |
| 執行期間錯誤 | 進入 CleanUp，關閉來源檔、還原畫面更新/警告，並顯示錯誤代碼與描述 |
