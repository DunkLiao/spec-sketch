# SPEC.md — Excel VBA 模組匯出工具

## 1. 專案概述

### 1.1 目的
提供一個圖形化桌面工具，讓使用者透過對話視窗選擇 `.xlsm` 檔案，
一鍵將檔案內所有 VBA 模組匯出為獨立檔案，以利**程式碼備份**與**版本控制（Git）**。

### 1.2 範圍
- ✅ 匯出標準模組、類別模組、使用者表單、文件模組
- ✅ 圖形化操作介面（選檔、選資料夾、匯出、重設）
- ✅ 匯出完成自動開啟資料夾
- ❌ 不含「匯入 / 還原」模組回 Excel 的功能（未來擴充）
- ❌ 不含批次多檔處理（未來擴充）

### 1.3 名詞定義
| 名詞 | 說明 |
|------|------|
| VBComponent | Excel VBA 專案中的單一元件（模組/表單） |
| 標準模組 | Type=1，一般 Sub/Function 存放處 |
| 類別模組 | Type=2，物件導向類別 |
| 使用者表單 | Type=3，UserForm |
| 文件模組 | Type=100，ThisWorkbook 與各 Sheet |

## 2. 功能需求（Functional Requirements）

| 編號 | 需求 | 優先級 |
|------|------|:------:|
| FR-01 | 使用者可透過對話視窗選擇來源 `.xlsm` 檔 | 必要 |
| FR-02 | 使用者可透過對話視窗選擇匯出資料夾 | 必要 |
| FR-03 | 選定來源檔後，自動帶入同層 `vba_export` 為預設輸出目錄 | 中 |
| FR-04 | 按「開始匯出」後，逐一匯出所有 VBA 模組 | 必要 |
| FR-05 | 標準模組（Type=1）匯出副檔名為 `.txt` | 必要 |
| FR-06 | 類別模組 `.cls`、表單 `.frm` 維持原副檔名 | 必要 |
| FR-07 | 空白文件模組自動略過，不產生空檔 | 中 |
| FR-08 | 匯出完成後自動開啟輸出資料夾 | 中 |
| FR-09 | 提供「重設」按鈕，清空選擇與紀錄 | 中 |
| FR-10 | 執行紀錄區即時顯示每支模組匯出狀態 | 中 |
| FR-11 | 未開啟 VBA 存取權限時，顯示明確的中文設定指引 | 必要 |

## 3. 非功能需求（Non-Functional Requirements）

| 編號 | 需求 |
|------|------|
| NFR-01 | 執行平台限 Windows，且需安裝 Microsoft Excel |
| NFR-02 | 支援 Python 3.8 以上 |
| NFR-03 | 匯出過程中若發生例外，須保證關閉 Excel 程序，不殘留 `EXCEL.EXE` |
| NFR-04 | 介面文字採用繁體中文 |
| NFR-05 | 可透過 PyInstaller 打包為單一 `.exe`，供無 Python 環境使用 |

## 5. 系統流程（Process Flow）

```
[啟動程式]
     │
     ▼
[選擇 .xlsm 來源檔] ──▶ 自動帶入預設輸出資料夾
     │
     ▼
[確認/選擇輸出資料夾]
     │
     ▼
[按「開始匯出」]
     │
     ▼
[開啟 Excel(COM) 隱藏視窗]
     │
     ▼
[存取 VBProject.VBComponents] ──失敗──▶ [顯示信任設定指引] ──▶ 結束
     │成功
     ▼
┌─────────────────────────────┐
│  逐一走訪每個 VBComponent    │
│  Type=1 → .txt              │
│  Type=2 → .cls              │
│  Type=3 → .frm              │
│  文件模組(空) → 略過         │
│  文件模組(有碼) → .txt       │
└─────────────────────────────┘
     │
     ▼
[關閉活頁簿 & 退出 Excel]（finally 保證執行）
     │
     ▼
[自動開啟輸出資料夾] ──▶ [顯示完成訊息]
```

## 6. 匯出對應規則

| VBA 元件類型 | Type 值 | 匯出副檔名 | 備註 |
|--------------|:------:|:----------:|------|
| 標準模組 | 1 | `.txt` | 內容為完整 VBA 原始碼 |
| 類別模組 | 2 | `.cls` | — |
| 使用者表單 | 3 | `.frm` | 另會產生 `.frx` 二進位 |
| 文件模組 | 100 | `.txt` | 無程式碼則略過 |

---

## 7. 使用者介面規格

| 元件 | 類型 | 說明 |
|------|------|------|
| 來源檔輸入框 + 瀏覽鈕 | Entry + Button | 選擇 `.xlsm` |
| 輸出資料夾輸入框 + 瀏覽鈕 | Entry + Button | 選擇輸出目錄 |
| 開始匯出鈕 | Button（綠） | 觸發匯出流程 |
| 重設鈕 | Button（灰） | 清空所有欄位與紀錄 |
| 執行紀錄區 | ScrolledText（唯讀） | 即時顯示進度 |

---

## 8. 錯誤處理

| 情境 | 處理方式 |
|------|----------|
| 未選來源檔 / 檔案不存在 | 彈出警告視窗，中止 |
| 未選輸出資料夾 | 彈出警告視窗，中止 |
| 無 VBA 專案存取權限 | 顯示信任中心設定指引 |
| 自動開啟資料夾失敗 | 於紀錄區提示，不中斷流程 |
| 其他例外 | 紀錄區顯示錯誤訊息 + 錯誤彈窗，finally 關閉 Excel |

---

## 9. 前置設定（必要）

> Excel → **檔案 → 選項 → 信任中心 → 信任中心設定 → 巨集設定**
> → 勾選 **「信任存取 VBA 專案物件模型」**

## 10. 驗收條件（Acceptance Criteria）

- [ ] AC-01：選擇含多種模組的 `.xlsm`，能完整匯出所有模組
- [ ] AC-02：標準模組匯出後副檔名為 `.txt` 且內容正確
- [ ] AC-03：空白 Sheet 模組不會產生檔案
- [ ] AC-04：匯出後自動開啟輸出資料夾
- [ ] AC-05：按重設鈕後，欄位與紀錄皆清空
- [ ] AC-06：未開權限時顯示中文設定指引，程式不崩潰
- [ ] AC-07：任何錯誤情境下背景無殘留 `EXCEL.EXE`
- [ ] AC-08：以 `pyinstaller vba_exporter.spec` 可成功打包出可執行的 `.exe`
