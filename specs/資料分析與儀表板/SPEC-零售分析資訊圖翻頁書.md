# SPEC: 零售分析資訊圖翻頁書

## 1. 背景與目標

本專案內容源自參加工研院 2026 年 8/19、8/26「客戶數據分析：AI 解讀消費者歷史數據高效行銷實作應用班（臺北班）」的學習整理。

製作流程是將課堂中的專有名詞以 Perplexity 查詢後，再利用 ChatGPT 產生資訊圖表，最後整理成翻頁式網頁，方便集中瀏覽、複習與展示。

目標是提供一個不需建置流程的靜態 RWD flip book 網頁，讓使用者可以在桌機、平板與手機上順暢查看 `infographics/` 目錄中的資訊圖。

## 2. 使用者體驗需求

- 使用者進入首頁後，應立即看到專案標題、課程背景說明、頁碼狀態與主圖閱讀區。
- 使用者可透過上一頁、下一頁、鍵盤方向鍵、觸控滑動與縮圖目錄瀏覽資訊圖。
- 使用者點擊主圖時，應開啟全螢幕放大檢視。
- 使用者可在深色與淺色模式間切換，切換結果需記憶在同一瀏覽器中。
- 手機版需優先呈現主圖內容，控制按鈕不得造成主圖與縮圖之間出現過大空白。
- 淺色模式下，頁碼、翻頁按鈕與主題切換按鈕文字必須保持可讀。

## 3. 功能規格

### 3.1 資訊圖資料

- 圖片來源固定為 `infographics/` 目錄中的 PNG 檔。
- 目前共 22 張資訊圖。
- 頁序由 `script.js` 中的 `PAGE_IMAGES` 明確定義，不依賴作業系統的檔名排序。
- 每張圖需包含：
  - `title`: 顯示標題。
  - `file`: 對應 PNG 檔名。

### 3.2 翻頁閱讀

- 桌機寬度 `>= 860px` 時使用雙頁展開。
- 寬度 `< 860px` 時使用單頁閱讀。
- 雙頁模式下一次翻 2 頁，單頁模式下一次翻 1 頁。
- 頁碼需顯示目前頁面範圍，例如 `3-4 / 22` 或 `9 / 22`。
- 頁碼與翻頁狀態需在縮圖跳頁、按鈕翻頁、鍵盤操作、觸控滑動後同步更新。
- 到達第一頁時，上一頁按鈕需停用。
- 到達最後一組頁面時，下一頁按鈕需停用。

### 3.3 縮圖目錄

- 縮圖目錄需包含所有資訊圖。
- 使用者點擊縮圖後，閱讀區需跳到對應頁面。
- 目前可見頁面對應的縮圖需標示 active 狀態。
- 桌機版縮圖以網格呈現。
- 手機版縮圖以水平滑動呈現，並使用較小卡片避免佔用過多高度。

### 3.4 Lightbox 放大檢視

- 點擊主圖需開啟 lightbox。
- Lightbox 需顯示目前圖片、標題與頁碼。
- Lightbox 中需支援上一張、下一張與關閉。
- 點擊背景或按下 `Escape` 可關閉 lightbox。
- Lightbox 開啟時，頁面背景不可捲動。

### 3.5 鍵盤與觸控操作

- 一般閱讀狀態：
  - `ArrowRight`: 下一頁。
  - `ArrowLeft`: 上一頁。
- Lightbox 開啟狀態：
  - `ArrowRight`: 下一張。
  - `ArrowLeft`: 上一張。
  - `Escape`: 關閉。
- 觸控滑動：
  - 水平滑動距離需達到門檻才觸發。
  - 主要垂直滑動不應誤觸翻頁。

### 3.6 深淺色模式

- 預設主題：
  - 若 `localStorage` 中已有 `flipbook-theme`，使用該值。
  - 若無儲存值，依 `prefers-color-scheme` 判斷。
  - 若無法判斷，預設深色。
- 支援值僅限 `dark` 與 `light`。
- 切換按鈕需：
  - 顯示目前模式標籤。
  - 更新 `aria-pressed`。
  - 將結果寫入 `localStorage`。
- 淺色模式下，控制元件文字需使用 `var(--text)`，避免白底白字。

### 3.7 頁首與頁尾

- 頁首需包含：
  - 英文 eyebrow: `Retail Analytics Infographics`
  - 標題: `零售分析資訊圖翻頁書`
  - 背景說明: `參加工研院2026年8/19、8/26 客戶數據分析：AI解讀消費者歷史數據高效行銷實作應用班(臺北班)，將上課專有名詞以perplexity查詢後利用chatgpt產生資訊圖表`
  - 深淺色切換按鈕。
  - 頁碼狀態。
- 頁尾需包含：
  - `@工研院2026年8/19、8/26 客戶數據分析：AI解讀消費者歷史數據高效行銷實作應用班(臺北班) Created by Dunk`

### 3.8 無 JavaScript fallback

- 在 JavaScript 無法執行時，頁面需透過 `<noscript>` 顯示全部資訊圖清單。
- Fallback 不需支援翻頁、縮圖互動或 lightbox。

## 4. RWD 與視覺規格

- 網頁最小寬度支援至 320px。
- 所有圖片以 3:2 比例呈現，不可變形。
- 主圖使用 `object-fit: contain`，避免裁切資訊圖內容。
- 手機版 `<= 560px`：
  - `.stage` 使用相對定位。
  - 翻頁按鈕浮在主圖左右側。
  - 縮圖卡片壓縮為較小尺寸。
  - 頁首文字與控制列需自然換行，不得互相重疊。
- UI 卡片圓角維持在 8px 以內。
- 色彩需避免干擾資訊圖內容，主視覺以閱讀清楚為優先。

## 5. 技術規格

- 專案型態：純靜態 HTML/CSS/JavaScript。
- 不使用 React、Vite 或其他前端建置工具。
- 主要檔案：
  - `index.html`: 頁面結構與靜態 fallback。
  - `styles.css`: RWD、翻頁書、lightbox、深淺色主題樣式。
  - `script.js`: 頁序、翻頁狀態、縮圖、lightbox、主題切換邏輯。
  - `test/flipbook.test.js`: Node.js 自動化測試。
- 本機執行方式：

```powershell
python -m http.server 8080
```

- 本機瀏覽：

```text
http://127.0.0.1:8080/
```

## 6. 測試與驗收條件

執行：

```powershell
npm test
```

驗收條件：

- 測試需全部通過。
- `PAGE_IMAGES` 需包含 22 張資訊圖且順序正確。
- 桌機雙頁與手機單頁翻頁規則正確。
- 頁碼、按鈕停用狀態與縮圖 active 狀態需同步。
- 鍵盤與觸控操作需符合規格。
- Lightbox 可開啟、切換與關閉。
- 手機版翻頁按鈕不得落到主圖下方形成第二列。
- 頁首背景說明與頁尾署名需存在。
- 深淺色切換 helper 行為正確。
- 淺色模式控制元件文字需保持可讀。
- `script.js` 需通過語法檢查：

```powershell
node --check script.js
```

## 7. 非目標

- 不提供後端 API。
- 不提供圖片上傳或線上編輯功能。
- 不提供搜尋、分類或標籤篩選。
- 不自動掃描 `infographics/` 產生頁序。
- 不壓縮或轉換原始 PNG 圖片。
- 不提供使用者登入、權限控管或分析追蹤。
