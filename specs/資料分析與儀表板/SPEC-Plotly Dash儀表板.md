# Plotly Dash儀表板 — 技術規格文件 (SPEC)

> 平台：Plotly Dash

## 1. 專案概述

### 1.1 目的
建置一套以 **Plotly Dash** 為核心的互動式儀表板，協助財務／會計人員快速檢視各**會計科目**的**差異金額**變動，聚焦異常科目，縮短人工比對報表的時間。

### 1.2 背景
現行差異分析多以 Excel 手動比對期初／期末金額，耗時且不易視覺化。透過本儀表板可動態連結資料庫，將差異金額以 **億元** 為單位呈現，並提供 TOP N 排行、趨勢與明細下鑽。

### 1.3 目標使用者
- 財務分析人員（日常差異檢視）
- 會計科目負責領組／主管（決策參考）
- 稽核與風控人員（異常追蹤）

---

## 2. 名詞定義

| 名詞 | 定義 |
|:---|:---|
| 會計科目 | 依會計制度分類的帳務項目，具科目代碼與科目名稱 |
| 差異金額 | 期末金額 − 期初金額（或本期 − 前期），可為正負值 |
| 億元換算 | 金額 ÷ 100,000,000，將元換算為億元以利閱讀 |
| TOP N | 依差異金額絕對值由大到小排序後取前 N 筆 |
| LTV 邏輯 | 交易明細與科目主檔的關聯（Ledger-to-Value）比對邏輯，用於彙總各科目金額 |
| 下鑽 (Drill-down) | 由彙總圖表點擊後檢視對應科目明細 |

---

## 3. 系統目標與範圍

### 3.1 系統目標
- 提供單一頁面即可掌握全公司會計科目差異概況。
- 支援日期區間、科目分類等多維度篩選。
- 金額單位可於「元／億元」間切換。
- 支援明細匯出（CSV／Excel）。

### 3.2 範圍內 (In-Scope)
- 差異金額 KPI、TOP N 圖、趨勢圖、明細表。
- 唯讀分析（不涉及帳務異動）。

### 3.3 範圍外 (Out-of-Scope)
- 會計傳票的新增／修改。
- 跨系統即時交易寫入。
- 使用者帳號管理（沿用既有 SSO）。

## 5. 資料需求

### 5.1 來源資料表（範例）

| 資料表 | 主要欄位 | 說明 |
|:---|:---|:---|
| `dim_account` | 會計科目代碼、會計科目名稱、科目分類 | 科目主檔 |
| `fact_balance` | 會計科目代碼、資料日期、期初金額、期末金額 | 餘額事實表 |

### 5.2 關鍵欄位

| 欄位 | 型別 | 說明 |
|:---|:---|:---|
| 會計科目代碼 | VARCHAR | 主鍵，關聯用 |
| 會計科目名稱 | VARCHAR | 顯示名稱 |
| 期初金額 | DECIMAL | 期初餘額（元） |
| 期末金額 | DECIMAL | 期末餘額（元） |
| 差異金額 | DECIMAL | 期末 − 期初（元） |

### 5.3 億元換算
差異金額(億元)呈現時預設保留 2 位小數。

## 6. 功能需求 (Functional Requirements)

| 編號 | 功能 | 說明 |
|:---:|:---|:---|
| FR-01 | KPI 卡片 | 顯示總差異金額、最大正差異科目、最大負差異科目、異常科目數 |
| FR-02 | TOP N 差異科目長條圖 | 依差異金額絕對值排序，可調 N 值（5/10/20） |
| FR-03 | 差異趨勢折線圖 | 依日期區間顯示科目差異金額走勢 |
| FR-04 | 明細表格 | 可篩選、排序、分頁的科目差異明細 |
| FR-05 | 日期區間篩選器 | 選擇分析的起訖日期 |
| FR-06 | 單位切換 | 於「元 / 億元」間切換所有金額顯示 |
| FR-07 | 資料匯出 | 匯出目前明細為 CSV / Excel |
| FR-08 | 科目分類篩選 | 依科目分類過濾圖表與表格 |

## 7. 頁面與版面配置

```
┌───────────────────────────────────────────────┐
│  Header：儀表板標題 + 單位切換                    │
├───────────────────────────────────────────────┤
│  Filter Panel：日期區間 | 科目分類 | TOP N        │
├───────────────────────────────────────────────┤
│  KPI Row： [總差異] [最大正] [最大負] [異常數]     │
├──────────────────────┬────────────────────────┤
│  TOP N 長條圖          │  差異趨勢折線圖           │
├──────────────────────┴────────────────────────┤
│  明細表格 (DataTable) + 匯出按鈕                  │
└───────────────────────────────────────────────┘
```

**主要 Dash 元件對應：**
- `dcc.DatePickerRange`：日期區間篩選
- `dcc.Dropdown`：科目分類、TOP N、單位切換
- `dcc.Graph`：TOP N 長條圖、趨勢折線圖
- `dash_table.DataTable`：明細表格（含篩選／排序／分頁）
- `html.Button` + `dcc.Download`：匯出功能

## 8. 互動與回呼設計 (Callback)

| Callback | Inputs | Outputs | 說明 |
|:---|:---|:---|:---|
| CB-01 更新 KPI | 日期區間、科目分類、單位 | 4 張 KPI 卡片 | 依篩選重算彙總指標 |
| CB-02 更新 TOP N 圖 | 日期區間、科目分類、TOP N、單位 | `dcc.Graph`(bar) | 重繪排行圖 |
| CB-03 更新趨勢圖 | 日期區間、科目分類、單位 | `dcc.Graph`(line) | 重繪趨勢 |
| CB-04 更新明細表 | 日期區間、科目分類、單位 | `DataTable.data` | 更新表格資料 |
| CB-05 匯出資料 | 匯出按鈕點擊、目前表格資料 | `dcc.Download` | 產生 CSV / Excel |

## 9. 非功能需求

| 類別 | 需求 |
|:---|:---|
| 效能 | 一般查詢頁面載入 < 3 秒；TOP N 圖重繪 < 1 秒 |
| 安全 | 沿用公司 SSO 驗證，僅授權人員可存取；連線採 HTTPS |
| 權限 | 依角色限制可檢視之科目分類 |
| 資料更新頻率 | 每日日終批次更新（可設定） |
| 相容性 | 支援 Chrome / Edge 最新兩個版本 |
| 可維護性 | 模組化程式結構，回呼與版面分離 |

## 11. 部署與環境

### 11.1 開發環境
